# common

The helpers every Ursatz part shares: one status set, file and folder helpers, strings, JSON, a hash, the job handle and the event bus. [Repository README](../../README.md).

`common/` builds the static library `ursatz_common` (headers `<common/*.h>`, names `common_*`), on libc, `m` and cJSON only. The library, the Analyzer, the Composer, the workshop and the GUI call it in place of their own copies (R-638); it is POSIX only (Linux and macOS). The layer table (`cmake/layer-table.txt`) puts it under everything: no part below may be reached from it.

| Header | What it holds |
|---|---|
| `status.h` | `UrsatzStatus` (`URSATZ_OK`, `REQUEST`, `UNSATISFIABLE`, `NOT_FOUND`, `CONFLICT`, `FORMAT`, `IO`, `CANCELLED`, `ALLOC`, `INTERNAL`), `UrsatzError {message, path}` (path a JSON Pointer or empty), `ursatz_status_name`, `ursatz_status_parse` (its inverse), `ursatz_error_set` (printf style, a NULL error is allowed, returns the status) |
| `files.h` | read a whole file (NUL-terminated), `common_file_write_atomic` (temporary file, fsync, rename, fsync of the folder), `common_file_append_sync`, make a folder (`common_dir_make` with its parents, `common_dir_create` one that must be new), remove a tree, list a folder (sorted, no dot entries), sync a folder, join paths, exists, is a folder, `common_path_join` and `common_path_join_alloc` (the one way to join two path parts: a trailing slash is not doubled, an empty folder part leaves the stored relative path, a path that does not fit is refused), `common_file_copy` (read, then the atomic write) and `common_dir_make_parent` (the folder that holds a path) (R-691) |
| `strings.h` | `CommonText` (a growing buffer with a sticky failure flag; printf and JSON-string appends), `CommonNames` (a sorted string list), `common_trim`, `common_compare_ci`, `common_utc_now` (`YYYY-MM-DDTHH:MM:SSZ`) |
| `json.h` | read and write a JSON file (the write is atomic), typed member readers (`common_json_string`, `common_json_add_string_or_null`, `common_json_add_string_if`, `_long` for whole numbers only, `_bool`), `common_json_indent` (the 2-space print), the one rational codec, and the reader for a document that is refused at its first problem (`CommonJsonReader`: `common_json_refuse`, `_bad`, `_require`, `_require_array`, `_read_whole`, `_require_whole`, `_require_bool`, `_read_time`, the path helpers; the codec keeps its own error type, result codes and message texts). The rational has three forms, each caller naming the ones it accepts: the object `{"num", "den"}` (`COMMON_RATIONAL_OBJECT`, written by `common_json_rational_object`, not reduced), the text `"n/d"` or `"n"` (`COMMON_RATIONAL_TEXT`; a caller that needs the slash checks for it), and a whole number (`COMMON_RATIONAL_INTEGER`). Two arrays stay as they are, each with its own reader: the playback `[num, den]` (`analyzer/src/export/playback.c`, read by `gui/frontend/public/score/playback-engine.js`) and the variant `distance_fraction` (`api_variants.c`, read by `cli/src/recognize.c`) (R-689) |
| `hash.h` | `common_fnv1a64` and `common_fnv1a64_hex`: the one FNV-1a 64 (moved from `library/model/core/content_hash`); `common_fnv1a64_u64` folds a 64-bit value as 8 bytes, least significant first (R-691) |
| `job.h` | `UrsatzJob`: the progress and cancel callbacks of a long call (replaces `ComposerJob`) |
| `events.h` | the event bus: publishers, subscribers with bounded queues, `reset` on overflow ([jobs and events](../../workshop/docs/jobs-and-events.md#events)) |

Tests are in `common/tests/` (`common_files`, `common_text`, `common_json`, `common_hash`, `common_events`, each with a valgrind twin where it has one). `tools/ci/check-primitives.sh` names `common/hash.c` as the owner of the FNV hash.
