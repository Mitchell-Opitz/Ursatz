forbid analyzer chain_build_ -- the Analyzer runs the chain whole, never one stage builder (it was check-chain-builds.sh)
forbid analyzer get_target_property\([^)]*SOURCE_DIR|\.\./library/tests -- an application reads no library sources
forbid composer get_target_property\([^)]*SOURCE_DIR|\.\./library/tests|\.\./analyzer/src -- an application reads no library or Analyzer sources
forbid gui get_target_property\([^)]*SOURCE_DIR|\.\./library/tests -- an application reads no library sources
forbid gui URSATZ_GUI_LIBRARY_DIR|URSATZ_GUI_TEST_URSATZ_DIR -- GUI tests read the root fixtures, not library folders
forbid analyzer URSATZ_ANALYZER_FIXTURE_DIR -- one fixtures folder
forbid composer/src ursatz_analyzer -- the Composer includes and links no Analyzer: it hears through the library chain and the Analyzer is its sibling (R-620); only the CLI and the GUI call both
forbid composer/CMakeLists.txt ursatz_analyzer -- the Composer links no Analyzer target (R-620)
forbid composer/src/CMakeLists.txt target_link_libraries\(ursatz_composer\s+(PUBLIC|INTERFACE)\s+(?!ursatz_common\b) -- a Composer consumer sees no library or Analyzer header, only the common part its API header names (R-639)
