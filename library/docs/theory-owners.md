# Theory owners

The library owner of each piece of theory the apps used to copy. [Docs index](README.md)

The theory the apps used to copy has one library owner each (R-217, R-223). Ports keep the app's rules, constants and tie-breaks; where the port differs, the last column says what the switch declares. Each library header names its owner.
