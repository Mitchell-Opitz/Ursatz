# Ursatz

Ursatz is a general-purpose, theory-neutral computational music platform. It provides a canonical representation of musical material that strictly separates events, structures, relationships, observations, interpretations, contexts, and provenance.

Layers L0 through L8 are implemented; L9 (I/O adapters, notation, performance, corpus, applications) has not started.

See [docs/BUILDING.md](docs/BUILDING.md) for build and test instructions, and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the layer model and current module status. Per-module detail lives under `docs/modules/`.
